# 🎮 JavaArcade

A **30-Day Java Game & Simulator Challenge** built to strengthen Java programming through daily hands-on projects.

The goal was simple: **build one Java console project every day for 30 days** and practice Core Java concepts by creating working applications.

# ▶️ How to Run

Open PowerShell and navigate to any project:

```powershell
cd C:\Desktop\JavaArcade\Day30-SmartCity
```

Compile:

```powershell
javac SmartCity.java
```

Run:

```powershell
java SmartCity
```

The same process can be followed for the other projects by using their respective folder and `.java` file names.
